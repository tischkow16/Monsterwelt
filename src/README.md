# Quellcode von Monsterwelt

- `game.js` – die komplette Spiel-Engine (Welt, Kämpfe, Menüs, Items …)
- `template.html` – HTML/CSS-Gerüst
- `m1.json` … `m7.json` – Monsterdaten (Generation 1–7)
- `build.py` – baut daraus die fertige Spieldatei

Bauen: im Ordner `src` `python3 build.py` ausführen → erzeugt `monsterwelt.html`.
Diese Datei wird dann als `index.html` im Hauptordner veröffentlicht.
