# Monsterwelt

Ein Monster-Abenteuer im Browser – fange Monster, besiege 10 Arenen und werde Champion!

▶️ **Jetzt spielen:** https://tischkow16.github.io/Monsterwelt/

Steuerung: Pfeiltasten / WASD zum Laufen, Enter / Leertaste zum Bestätigen, Esc für das Menü.
Auf dem Handy gibt es Touch-Steuerung.

## Online & App
- 🌐 **Online spielen:** Account erstellen, Freunde in der Welt sehen, Spielstand liegt sicher auf dem Server (mit Schummel-Schutz).
- 📲 **Als App:** Am Handy „Zum Startbildschirm hinzufügen“, am PC in Chrome/Edge auf „Installieren“ klicken.
- Server-Code: Ordner `server/` (Cloudflare Worker + D1-Datenbank), wird automatisch per GitHub Actions hochgeladen.
